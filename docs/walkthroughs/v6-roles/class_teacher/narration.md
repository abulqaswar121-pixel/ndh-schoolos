Actual application components with fictional demo records. Not live authentication, native installation, bank verification or physical printing. Selected English voice-02, not a verified Nigerian accent.

## 0:00 · School link & sign-in

Open your school's branded link. Staff and parents use their registered phone and four-digit PIN. This recording uses fictional demo records and a local session, not live authentication.

## 0:13 · Assigned-class attendance

Open Attendance and check your assigned class and date. Mark the demo class present, then inspect the attendance summary. Change only the learners you are responsible for.

## 0:27 · One account: class & subjects

Choose Results and Report Cards. The Subject Marksheet holds C A and exam scores. Your class and subject assignments stay in one account; this build uses the real menu labels shown here.

## 0:43 · Class broadsheet → A4 report

Open Class Broadsheet and Report Cards. Inspect the subject totals, then open a report card. The same A four page scales down on a phone without rearranging the document.

## 0:59 · Optional Tahfeez / Halqah variant

This next demo uses an enabled Quran programme. Open Quran Progress for Surah, Ayah and revision fields. If your school uses Mumtaz or Jayyid, confirm how those ratings map to this build. Conventional schools leave this module off.

## 1:18 · Install school app

Open your school's link and choose Install school app. The real help dialog explains Safari and Chrome steps. A native installation is not being verified here.

## 1:31 · Offline drafts & reconnect

Sign in online and open needed records before offline work. Attendance and score drafts can sync when reconnected; review conflicts. Payments, messages and new sign-ins need internet. This demo does not verify live sync.
